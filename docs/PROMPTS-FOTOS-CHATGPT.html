Prompts de Foto para ChatGPT

Un prompt JSON exacto por cada toma faltante de cada producto. Cada prompt ya lleva embebido «el pedazo de nosotros» — la identidad de marca, la cámara, el modelo, las locaciones y las prohibiciones. Tú solo adjuntas la foto real del producto y generas.

Cómo usar

  1. Elige el producto y la toma que necesitas abajo.
  2. Pulsa Copiar JSON — el prompt completo (marca + toma) queda en tu portapapeles.
  3. En ChatGPT, pega el JSON y adjunta la foto real del producto en el mismo mensaje. El campo <<ADJUNTA AQUÍ LA FOTO REAL DEL PRODUCTO>> es solo un recordatorio — la foto se sube como archivo, no se escribe.
  4. Si la toma pide varios colores, genera una imagen por color listado en colores_requeridos.
  5. Guarda con el nombre que indica entrega (ej. travel-bag-i—hero-editorial—cognac.jpg).
